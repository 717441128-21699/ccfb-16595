# LINEUP · 浪壁竞速 / Surf Wall Physics

一个使用 **WebGL2 + TypeScript** 实现的冲浪运动小游戏。游戏不是简单地把板贴在移动斜坡上：涌浪先按色散、群速度和浅化从深水传播到浅滩，再由海底坡度与波陡计算伊里巴伦数和破碎类型；冲浪板根据重力、浪面水流、板底升力、尾舵/板缘侧向力和重心输入进行三维约束物理积分。

## 运行

```bash
npm install
npm run dev
```

构建与类型检查：

```bash
npm run build
npm run preview
```

## 页面与路由

- `#/spots`：浪点选择。四个虚构浪点，各自带水下地形、涌浪高度/周期、坡度、伊里巴伦数、破碎比例和速度量级。
- `#/surf/:spotId`：WebGL2 冲浪页。
- `#/science/:spotId`：浪的剖面讲解页，含深水 → 浅滩 → 破碎的动画剖面图和完整公式。
- `#/judging`：比赛评分页，读取本机保存的浪段记分卡、五名裁判分、评分维度和 Heat 排名。

## 操作

| 输入 | 动作 |
| --- | --- |
| `A / ←`、`D / →` | 压内/侧板缘，控制尾舵角和切转 |
| `W / ↑` | 重心压前脚，纵向加速 |
| `S / ↓` | 重心压后脚，减速/加强转向 |
| `Space / J` | 起跳；空中 `A/D` 转体 |
| `Shift / G / K` | 空中抓板，增加动作分 |
| `P / Esc` | 暂停 |
| `R` | 重开 |

触屏设备会显示转向、前后重心、抓板和起跳按钮。

## 物理模型要点

坐标约定：`X` 指向岸边/浪传播方向，`Z` 为沿岸线和剥离方向，`Y` 向上。

1. 深水波：

   \[
   L_0=\frac{gT^2}{2\pi},\qquad c_0=\frac{L_0}{T}
   \]

2. 有限水深色散，使用 Newton/Bisection 求解：

   \[
   \omega^2=gk\tanh(kh)
   \]

3. 能量通量守恒下的浅化：

   \[
   H(x)=H_0\sqrt{c_{g0}/c_g(x)}
   \]

4. 伊里巴伦数与破碎分类：

   \[
   \xi=\frac{\tan\beta}{\sqrt{H_0/L_0}}
   \]

   - `ξ < 0.4`：崩浪 / spilling
   - `0.4 ≤ ξ < 2.0`：卷浪、管浪 / plunging
   - `2.0 ≤ ξ < 3.2`：坍卷 / collapsing
   - `ξ ≥ 3.2`：涌碎 / surging

5. 破碎比例：代码搜索 `H/h_m` 达到破碎指数 `γ ∈ [0.70,0.90]` 的位置。为了同时满足题目字面所说的“破碎水深 / 浪高”，项目把从前方碎波槽到海床的水深记为 `d_b = h_m - H_b/2`；所选 γ 使 `d_b/H_b` 也落在 `0.70–0.90`。讲解页同时显示 `H_b/h_m` 标准破碎指数。

6. 板的受力：
   - 重力 `m g`
   - 浪面水流相对速度的二次阻力/推力
   - `F_L = 1/2 ρ v² A C_L` 板底升力，方向随压缘倾斜
   - 由舵角和侧滑角产生的尾舵侧向力
   - 前后重心产生的纵向驱动/刹车

破碎点波速约为 `4.9–6.2 m/s`，可调物理下最大板速约为 `7–11 m/s`，HUD 会显示实时 `v_max / c_b`，正常量级约为 `0.7–1.8×`。
